
# Biblioteca documental C4

Esta carpeta está destinada a almacenar los documentos de formación y consulta del Portal de Operadores C4.

## Organización

- `manuales/`: manuales de operación y consulta.
- `protocolos/`: protocolos y procedimientos.
- `capacitacion/`: presentaciones, guías y materiales formativos.

## Consideraciones

- Incorporar únicamente documentos autorizados para su publicación.
- Utilizar nombres de archivo claros y descriptivos.
- Verificar que los documentos no contengan información reservada o datos personales que no deban publicarse.
- Mantener actualizadas las versiones disponibles.
